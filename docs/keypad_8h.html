Function Documentation

◆ kp_scan()

void kp_scan ( keypad_t * kpad)

Ejecuta UNA transición de la FSM de escaneo (no bloqueante).

Debe invocarse repetidamente desde el super-loop del Core 0. Un ciclo completo (4 filas × 3 fases) requiere múltiples llamadas; la duración de cada llamada es de nanosegundos a pocos microsegundos. No contiene ningún sleep_us() ni busy-wait.
