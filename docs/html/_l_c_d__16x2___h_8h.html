Detailed Description

Driver para LCD 16×2 Hitachi HD44780 en modo de 4 bits (GPIO bit-bang).

Note
Este driver es bloqueante por diseño (usa sleep_us/sleep_ms). En la arquitectura LAB3 Multicore, esto es ACEPTABLE porque el LCD opera exclusivamente en el Core 0, y el Core 1 (DAC) es completamente independiente. Las demoras del LCD ya NO introducen jitter en la señal.
