Detailed Description

Máquina de estados de la interfaz de usuario del Generador de Señales.

Note
LAB4: Este módulo opera exclusivamente en Core 0. La bandera params_changed dispara el pre-cálculo (signal_precalculate()) que produce el nuevo buffer para el Core 1.
